## 🎯 Pilares Estratégicos
1. **Evitar ambigüedad:** No usar "GEO" a secas. Usar siempre "GEO SEO", "Optimización para IA" o "Visibilidad en ChatGPT".
2. **Autoridad Temática (EEAT):** Demostrar experiencia técnica real (Oscar Ochoa, Ing. Mecatrónico).
3. **Estructura RAG-Friendly:** Contenido fácil de extraer por IAs (Listas, tablas, definiciones claras).

## 📝 Guía de Redacción de Artículos (Template)

Para que el artículo sea citado por una IA, debe seguir esta estructura:

### 1. El Gancho (H1 + Intro)
- **Título sugerido:** Debe ser una pregunta o una solución directa (Ej: "¿Cómo posicionar mi negocio en las IAs en 2026?").
- **Intro:** Primeras 100 palabras deben definir el concepto clave.

### 2. Definición Directa (Featured Snippet / IA Answer)
- Un bloque `<blockquote>` o un párrafo resaltado con la definición exacta del tema. Ejemplo: *"El GEO SEO es la técnica de..."*.

### 3. Estructura de Cuerpo (H2 - H3)
- Usar listas numeradas para procesos.
- Usar tablas para comparaciones (las IAs aman las tablas).

### 4. Datos Estructurados (Fira Code Blocks)
- Incluir un pequeño bloque de Schema JSON-LD específico para el tema del artículo.
